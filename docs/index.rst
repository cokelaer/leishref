Leishmania Reference Genome Database
=====================================

.. image:: logo.png
   :width: 200px
   :align: center

A curated catalog of Leishmania genomes that ships inside the package.
``pip install leishref`` is the only entry point you need: no hunting across NCBI,
TriTrypDB and Zenodo to find out what exists or where it lives.
