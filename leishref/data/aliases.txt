# NAMING RULES:
# - Species code: L + 1-2 letter abbreviation
#   * Unambiguous (1 letter): Ld (donovani), Lm (major), Li (infantum)
#   * Ambiguous t-species (2 letters): Ltr (tropica), Lta (tarentolae), Ltu (turanica)
#   * Ambiguous a-species (2 letters): Lad (adleri), Lae (aethiopica), Lam (amazonensis), Lar (arabica)
#   * Other species: L + 2 letters (e.g., Lb=braziliensis, Le=enriettii, Lg=guyanensis)
# - Strain discriminator: appended to species code (e.g., Ld1S, LdBPK, LtrL590)
# - WHO strain nomenclature (MHOM/MCAN/MCEB/MDAS/etc.): kept as-is for tracking provenance
#   * MHOM = Mammalian Human origin (e.g., MHOM/BR/75/M2904: Brazil, 1975, human isolate M2904)
#   * MCAN = Mammalian CANine (dog)
#   * MCEB = Mammalian CEB (other mammal, e.g., Cerdocyon)
#   * MDAS = Mammalian DASyprocta (rodent)
#   * Full format: XXXX/COUNTRY/YEAR/ID; aliases preserve it: LdMHOM_BR_75_M2904
# - RefSeq/GenBank: GCF has no suffix; GCA with same assembly gets _GCA suffix
# - Same strain, several assemblies: suffix with release year (e.g., LpaMHOM_PA_94_PSC-1_2014,
#   LpaMHOM_PA_94_PSC-1_2025) or submitter tag (_USP); same year -> append b, c (…_2017, …_2017b)
# - Never include ATCC numbers, ASM identifiers, or annotation notes (they live in metadata.yaml)
# - Leishmania sp.: Lsp + isolate/place (LspGhana, LspNamibia, LspLEM2494)
# - Special cases: descriptive suffix like _kinetoplast
#

# are excluded by default from plot commands (plot-sizes, plot-histogram) to avoid
# outliers. Use --include-kinetoplast flag to include them.
